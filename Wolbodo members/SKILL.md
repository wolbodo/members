Read the README.md file within this skill, and explore the other available files.

If creating visual artifacts (prototypes, mocks, slides), copy assets out and create static HTML files. Use `colors_and_type.css` for all tokens. Import the Outfit + Chivo Mono fonts from Google Fonts.

If working on production code, read the design guidelines in README.md and apply the token system from `colors_and_type.css`.

**Brand character:** warm near-black dark theme, single teal accent (#00c4a0), Outfit sans + Chivo Mono, no gradients, no emoji, dry copy. Funky but functional — the UI for a society of weirdos who take usability seriously.

If invoked without guidance, ask the user what they want to build, ask a few questions about audience and scope, then act as an expert designer who outputs HTML artifacts or production-ready CSS/JSX.
